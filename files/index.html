📋 使用说明

如何上传文件

  1. 将文件复制到 source/uploads/ 目录
  2. 编辑 source/_data/files.json 文件，添加新文件的信息
  3. 重新生成网站：hexo clean && hexo generate

支持的文件格式

  • 文档类: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX
  • 图片类: JPG, JPEG, PNG, GIF
  • 压缩包: ZIP, RAR
  • 代码类: MD, TXT, JS, HTML, CSS
