📤 如何上传文件？

由于Hexo是静态博客，需要手动上传文件：

  1. 本地操作：将文件复制到 source/uploads/ 目录
  2. Git操作：将文件提交到Git仓库
  3. 重新生成：运行 hexo clean && hexo generate
